# Models & Cost
Default: zero model cost (rules + keyword retrieval). LLM is invoked only for detected questions with no local evidence, never in Called On until the user calls, never in DND, capped by `token_budget` per session (default 20k tokens), cached per normalized question, and failures fall back to rules.
Configure: COMPANION_PROVIDER=openai|anthropic, COMPANION_BASE_URL, COMPANION_MODEL, COMPANION_API_KEY, COMPANION_CLOUD_OPT_IN=1, optional COMPANION_PRICE_IN_PER_MTOK / _OUT_ for estimates. Cost panel shows tokens always and cost only as an *estimate* when you set prices. Model comparison tables are intentionally not included (prices change; not measured here). Not implemented: provider routing, prompt caching at the API level, local LLM runner (any OpenAI-compatible local endpoint should work via BASE_URL, untested).
